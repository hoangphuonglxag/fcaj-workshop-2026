This section summarizes the weekly worklog throughout the **Workforce Bootcamp - First Cloud AI Journey (FCAJ)** program with a specialized focus on **Cloud Data Engineering**.

The 12-week roadmap covers foundational cloud computing, network infrastructure, storage, databases, data pipelines, distributed processing, modern data lakehouse architectures, and cost optimization:

### 📌 12-Week Internship Roadmap (Cloud Data Engineer Track):

* **[Week 1: Onboarding, AWS Fundamentals, IAM & Compute (EC2, CLI)](1.1-week1/)**
  * FCAJ culture, AWS Global Infrastructure, Identity & Access Management (IAM), AWS CLI setup, and EC2 instance management.

* **[Week 2: Networking & Security: Custom VPC, Subnets, NAT & VPC Endpoints](1.2-week2/)**
  * Designing Multi-AZ VPC architectures, configuring Public/Private Subnets, NAT Gateways, Security Groups/NACLs, and VPC Endpoints for secure data workloads.

* **[Week 3: Storage & Databases: Amazon S3 Data Lake, RDS & DynamoDB](1.3-week3/)**
  * Mastering Amazon S3 as the Data Lake foundation, data partitioning, lifecycle rules, relational databases (RDS), and NoSQL (DynamoDB).

* **[Week 4: Serverless Computing & Pipeline Automation: Lambda, S3 Triggers, CloudWatch](1.4-week4/)**
  * Event-driven processing with AWS Lambda, automated ETL triggers on S3 object creation, and monitoring with Amazon CloudWatch & EventBridge.

* **[Week 5: Real-time Ingestion & Streaming: Kinesis & MSK (Kafka)](1.5-week5/)**
  * Ingesting streaming data with Amazon Kinesis Data Streams / Firehose and Amazon Managed Streaming for Apache Kafka (MSK).

* **[Week 6: Metadata Management & Serverless Querying: Glue Catalog & Athena](1.6-week6/)**
  * Schema crawling with AWS Glue Crawler, metadata cataloging, and serverless ad-hoc SQL querying using Amazon Athena.

* **[Week 7: Batch ETL & Data Transformation: AWS Glue & PySpark](1.7-week7/)**
  * Developing Glue ETL jobs for raw data transformation, format optimization (Parquet/Iceberg), and data cleansing at scale.

* **[Week 8: Distributed Data Processing: Amazon EMR & Apache Spark](1.8-week8/)**
  * Provisioning and managing Amazon EMR clusters for large-scale distributed analytics with Apache Spark and Hadoop.

* **[Week 9: Modern Cloud Data Warehousing: Amazon Redshift & Serverless](1.9-week9/)**
  * Table design, Distribution and Sort Keys, and loading large datasets into Amazon Redshift for BI analytics.

* **[Week 10: Workflow Orchestration: Apache Airflow on Amazon MWAA](1.10-week10/)**
  * Orchestrating complex end-to-end data pipelines using Apache Airflow DAGs managed by Amazon MWAA.

* **[Week 11: Data Governance, Security & Cost Optimization](1.11-week11/)**
  * Granular row/column-level access control via AWS Lake Formation, KMS encryption, and cloud cost management.

* **[Week 12: Workshop Completion, Capstone Project & Internship Finalization](1.12-week12/)**
  * Finalizing the end-to-end cloud data pipeline capstone, documentation, and presenting the final internship defense.
